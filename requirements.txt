#
# Install into a venv created with a native ARM64 interpreter (see docs/setup.md):
#   .\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.txt
#
# torch and torchvision have no win-arm64 wheels on PyPI; the official builds
# come from the PyTorch package index. Both are pinned exactly (including the
# local version label) so pip can never fall back to the unrelated, ancient
# pure-Python torchvision releases on PyPI.
#
# TensorFlow and tf2onnx are intentionally absent: neither works natively on
# win-arm64. Keras models are trained and converted off-device.
